เกี่ยวกับฉัน

ผมสนใจด้านการพัฒนาเว็บไซต์และระบบงาน ชอบเรียนรู้สิ่งใหม่ ๆ และสนุกกับการได้ลองลงมือทำจริง ที่ผ่านมาได้เรียนรู้การเขียนเว็บไซต์ผ่านโปรเจกต์ต่าง ๆ ทั้งงานเดี่ยวและงานกลุ่ม รวมถึงมีโอกาสทำงานด้าน QA Testing ในช่วงสหกิจศึกษา ทำให้ได้เรียนรู้กระบวนการทดสอบระบบ การตรวจสอบข้อผิดพลาด และการทำงานร่วมกับผู้อื่น

ตอนนี้กำลังพัฒนาทักษะด้าน HTML, CSS, JavaScript, PHP และ SQL Server โดยตั้งใจอยากนำความรู้ที่มีไปต่อยอดในการทำงานจริง และพัฒนาตัวเองให้เก่งขึ้นในสายงาน IT
